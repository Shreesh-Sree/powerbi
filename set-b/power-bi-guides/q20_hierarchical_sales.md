# Q20 Hierarchical Sales Analysis
Create hierarchy Country > State > City (right-click Country field > Create hierarchy; drag State and City in; optionally add Product).
Drill down: bar chart with hierarchy on Axis, turn on drill mode, use expand-next-level.
Drill through: page `City Detail` with City in the drill-through well; table of products, customers, sales. Right-click a bar > Drill through.
Visuals: map (sales by state), bar (city), table (product-level sales), cards.
