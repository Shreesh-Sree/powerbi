# Q22 Interactive Sales Report using Bookmarks
One page, three visual groups: Sales (sales by month), Profit (profit by category), Quantity (qty by product). View > Selection pane > group and rename.
Hide two groups, View > Bookmarks > Add `Sales`; repeat for `Profit`, `Quantity`.
Insert > Buttons > Blank, label each, Format > Action > Type Bookmark > pick the bookmark. Test with Ctrl+Click.
