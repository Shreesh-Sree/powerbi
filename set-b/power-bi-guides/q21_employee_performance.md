# Q21 Employee Performance Dashboard
Measures: Avg Rating, Tasks Completed, Target Achievement % = DIVIDE([Achieved],[Target]).
Visuals: KPI (Achievement vs Target), Cards, Matrix (Employee x Month), Column chart by Department.
Conditional formatting: Format > Cell elements > Background colour > rules (>=100% green, <70% red) or gradient; icons for trend.
Slicers: Department, Year. View > Sync slicers: enable Sync and Visible across pages.
