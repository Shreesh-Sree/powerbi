# Q23 Custom Tooltip and Drill-Through
Tooltip: new page, Format page > Allow use as tooltip ON, page size Tooltip, add cards (Sales, Qty, Avg price) and a mini chart. On the target visual: Format > General > Tooltips > Type Report page > select page.
Drill-through: page `Customer Detail` with Customer (or Product) in drill-through well, Keep all filters ON, table of orders and sales. Right-click a data point > Drill through.
