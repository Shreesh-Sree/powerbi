# SD0107 MCQs with Answers (50)
Each question is followed by its options and the correct answer.

### 1. Which Power BI component is used on a Windows computer to build reports and data models?
- A) Power BI Service
- B) Power BI Desktop
- C) Power BI Mobile
- D) Power BI Report Server

**Answer: B) Power BI Desktop**

### 2. Which language is used to create measures and calculated columns in Power BI?
- A) DAX
- B) SQL
- C) M
- D) R

**Answer: A) DAX**

### 3. Which language is used behind the transformations in the Power Query Editor?
- A) M
- B) DAX
- C) MDX
- D) C#

**Answer: A) M**

### 4. Which view in Power BI Desktop is mainly used to create and manage relationships between tables?
- A) Report view
- B) Table view
- C) DAX query view
- D) Model view

**Answer: D) Model view**

### 5. A Customer table is related to a Sales table, where one customer can have many sales. Which relationship type is this?
- A) Many-to-many
- B) One-to-one
- C) One-to-many
- D) Circular

**Answer: C) One-to-many**

### 6. Which Power Query operation breaks one column into several columns using a delimiter such as a comma?
- A) Merge Columns
- B) Split Column
- C) Pivot Column
- D) Group By

**Answer: B) Split Column**

### 7. What does "Append Queries" do in Power Query?
- A) Joins two tables side by side using a key column
- B) Removes duplicate rows
- C) Stacks the rows of one table below another table
- D) Creates a pivot table

**Answer: C) Stacks the rows of one table below another table**

### 8. "Merge Queries" in Power Query is similar to which SQL operation?
- A) UNION
- B) GROUP BY
- C) JOIN
- D) ORDER BY

**Answer: C) JOIN**

### 9. Which DAX function returns the total of all numbers in a column?
- A) TOTAL
- B) SUM
- C) ADD
- D) COUNTROWS

**Answer: B) SUM**

### 10. Which DAX function is used to change the filter context of a calculation?
- A) RELATED
- B) CALCULATE
- C) VALUES
- D) SUMX

**Answer: B) CALCULATE**

### 11. Which DAX function returns the number of rows in a table?
- A) SUMX
- B) RELATED
- C) VALUES
- D) COUNTROWS

**Answer: D) COUNTROWS**

### 12. Which DAX function fetches a value from the "one" side table into the "many" side table?
- A) RELATED
- B) LOOKUP
- C) VLOOKUP
- D) FETCH

**Answer: A) RELATED**

### 13. Which statement about measures in Power BI is correct?
- A) They are calculated at query time based on the filter context
- B) They are stored as a value for every row in the table
- C) They are created in the Power Query Editor
- D) They cannot be used in visuals

**Answer: A) They are calculated at query time based on the filter context**

### 14. Which DAX function returns the number of unique values in a column?
- A) DISTINCTCOUNT
- B) COUNTDISTINCT
- C) UNIQUECOUNT
- D) DCOUNT

**Answer: A) DISTINCTCOUNT**

### 15. Which DAX function calculates a year-to-date total?
- A) YEARTODATE
- B) SUMYTD
- C) YTDSUM
- D) TOTALYTD

**Answer: D) TOTALYTD**

### 16. For time-intelligence functions to work properly, a Date table should contain:
- A) A continuous range of dates with no gaps
- B) Only month names
- C) Only working days
- D) Dates stored as text

**Answer: A) A continuous range of dates with no gaps**

### 17. Which visual is most suitable for showing a trend over time?
- A) Pie chart
- B) Treemap
- C) Card
- D) Line chart

**Answer: D) Line chart**

### 18. Which visual is best for showing the relationship between two numeric variables?
- A) Card
- B) Donut chart
- C) Funnel chart
- D) Scatter chart

**Answer: D) Scatter chart**

### 19. Which visual is used to display a single number such as total sales?
- A) Matrix
- B) Slicer
- C) Funnel
- D) Card

**Answer: D) Card**

### 20. Which visual lets report users interactively filter the other visuals on a page?
- A) Slicer
- B) Card
- C) Gauge
- D) Treemap

**Answer: A) Slicer**

### 21. How does a Matrix visual differ from a Table visual?
- A) It supports grouping on both rows and columns, like a pivot table
- B) It cannot display numbers
- C) It shows only one column
- D) It shows only images

**Answer: A) It supports grouping on both rows and columns, like a pivot table**

### 22. Which feature lets a user move from a summary level (e.g., Year) to a detailed level (e.g., Month) inside a visual?
- A) Bookmark
- B) Drill down
- C) Q&A
- D) Theme

**Answer: B) Drill down**

### 23. What is the purpose of a Bookmark in a Power BI report?
- A) To schedule data refresh
- B) To create relationships
- C) To capture the current state of a page, including filters and visibility
- D) To write DAX formulas

**Answer: C) To capture the current state of a page, including filters and visibility**

### 24. What is a Power BI dashboard?
- A) A single-page canvas of pinned visuals in Power BI Service
- B) A multi-page report created in Power BI Desktop
- C) A data source connector
- D) A DAX table

**Answer: A) A single-page canvas of pinned visuals in Power BI Service**

### 25. Where can a report be published so that colleagues can view it online?
- A) Power Query Editor
- B) DAX Studio
- C) Microsoft Word
- D) Power BI Service

**Answer: D) Power BI Service**

### 26. Which connectivity mode loads a copy of the data into Power BI's memory?

- B) Import
- C) Live Connection
- D) Streaming

**Answer: B) Import**

### 27. What happens in DirectQuery mode?
- A) All data is copied into the .pbix file
- B) The report works without any data source

### 28. Which file extension is used for Power BI Desktop report files?
- A) .pbi

**Answer: B) .pbix**

### 29. What is Row-Level Security (RLS) used for?

- B) Creating new visuals

- D) Merging two tables

**Answer: C) Restricting which rows of data different users can see**

### 30. What is the role of an on-premises data gateway?

- B) Designs report visuals

**Answer: A) Connects Power BI Service to on-premises data sources for refresh**

### 31. Which Power Query option removes repeated rows from a table?
- A) Remove Errors
- B) Remove Duplicates
- C) Keep Top Rows
- D) Fill Down

**Answer: B) Remove Duplicates**

### 32. What does "Unpivot Columns" do in Power Query?
- A) Converts rows into columns
- B) Converts selected columns into attribute–value rows

**Answer: B) Converts selected columns into attribute–value rows**

### 33. In a star schema, the central table that holds transactional numeric data is called the:
- A) Dimension table
- B) Lookup table
- C) Fact table
- D) Parameter table

**Answer: C) Fact table**

### 34. What does the cross-filter direction "Both" in a relationship allow?

**Answer: A) Filters to flow in both directions between the two tables**

### 35. Which DAX function performs division and safely handles divide-by-zero errors?

**Answer: B) DIVIDE**

### 36. A measure Total Sales = SUM(Sales[Amount]) is placed in a visual with Region on the axis. What does it show?

- C) The total Amount for the East region only
