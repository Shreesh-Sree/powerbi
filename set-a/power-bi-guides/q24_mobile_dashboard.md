# Q24 Mobile-Friendly Banking Dashboard
1. Finish the desktop report (cards: Total Deposits, Active Accounts; bar: Deposits by Branch; line: Deposits trend).
2. View > **Mobile layout**. Drag only important visuals (cards on top, one chart, then a table) from the Page visuals pane onto the phone canvas. Visuals snap to a grid; keep them full width.
3. Design rules: fewer than 5 visuals, large numbers, one slicer at the top, no tiny labels (font >= 10-12 pt), avoid wide matrices, set alt text, use the same theme.
4. Different screen sizes: the phone canvas scales automatically; check portrait in the Power BI Mobile app after publishing (Service > report > View on mobile / scan QR). Set page size to 16:9 for desktop, mobile layout is separate. Lock the layout in the app if needed.
