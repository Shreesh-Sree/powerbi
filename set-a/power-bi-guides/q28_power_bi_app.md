# Q28 Power BI App for Banking Users
1. Workspace `Banking Analytics`: publish reports (Branch Performance, Customer, Transactions) and dashboards (pin visuals).
2. Workspace > **Create app**. Setup: name, description, logo, theme colour, contact. **Content**: add the reports and dashboards, set landing page (a dashboard or report), order/rename sections.
3. **Audience**: Entire organization, or specific users/groups (branch managers). Optionally create multiple audiences and choose per-item visibility.
4. **Publish app**. Users install from Apps > Get apps. Verify permissions: the app respects dataset RLS, use "Preview as audience" or sign in as a branch manager, confirm they see only assigned content; update the app after changes (Update app).
